# Pixel Run

A colorful, original 8-bit side-scrolling platform adventure inspired by classic arcade platformers.

## Play

Open `index.html` in a modern browser. Use **← / →** or **A / D** to move, and **Space**, **↑**, or **W** to jump. Collect coins, stomp enemies, and reach the flag.

No build tools or dependencies are required. Your high score is saved in the browser.
